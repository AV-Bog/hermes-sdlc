# Задача: очередь задач по HTTP

В каталоге нет кода. Нужен HTTP-сервис на Python, только стандартная библиотека, запуск
`python3 server.py`, слушает порт 8000.

`POST /jobs` с JSON-телом `{"type": "...", "payload": ...}` создаёт задачу и сразу отвечает
JSON с её идентификатором в поле `id`. Задача выполняется в фоне: ответ на приём не ждёт её
окончания.

`GET /jobs/<id>` отдаёт JSON с состоянием задачи и результатом, когда он готов. Пока задача
не выполнена, в ответе должно быть видно, что она ещё идёт.

Типы задач:

- `echo` - результатом становится payload целиком;
- `sleep` - payload это число секунд, результатом становится строка `ok`.

Ошибки клиента - ответ 4xx, а не 500: тело не JSON, нет обязательного поля, неизвестный тип
задачи. Запрос несуществующей задачи - 404.

Клиенты - внешние скрипты, ходят параллельно. Принятая задача не должна теряться: после
ответа 2xx она обязана дойти до результата. Повторное чтение результата не меняет его.
