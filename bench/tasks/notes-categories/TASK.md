# Задача: заметки с категориями

В проекте консольная утилита заметок на Python, только стандартная библиотека. Сейчас она умеет
`add`, `list`, `search` и `delete`. Поведение описано тестами в `test_notes.py` - они зелёные.

Нужно добавить категории.

## Что добавить

- `add --cat <категория> <текст>` - заметка с категорией. Без `--cat` работает как раньше.
- `list --cat <категория>` - только заметки этой категории. Без флага - все, как раньше.
- `stats` - по одной строке на категорию: категория, символ табуляции, количество. Категории
  по алфавиту. Заметки без категории в вывод не попадают.

## Ограничения

- Файл заметок, созданный текущей версией, должен открываться новой без правок и без потери
  записей.
- Существующие команды должны работать как раньше: тот же вывод, те же коды возврата.
- Существующие тесты в `test_notes.py` менять нельзя: они описывают текущее поведение. Свои
  проверки можно добавить - отдельным файлом или ниже существующих.
